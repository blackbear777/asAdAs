# TZARR Client — starter

Fabric 1.21.1 / Java 21 starter project.

Included:
- Right Shift HUD toggle
- CPS counter that measures real clicks
- R key CPS reset
- Fabric keybind framework
- Clean structure for adding client-side practice features

Build with:
  ./gradlew build

Output:
  build/libs/

This starter does not generate clicks or automate aiming, and does not implement wallhack-style ESP.
